PS4 ULTIMATE STORE — сайт для публикации

Файл index.html — главная страница сайта.

Самый простой бесплатный способ опубликовать:
1. Создай аккаунт GitHub, если его ещё нет.
2. Создай новый публичный репозиторий, например ps4-ultimate-store.
3. Загрузи в него index.html в корень репозитория.
4. Открой Settings → Pages.
5. В разделе Build and deployment выбери Deploy from a branch.
6. Выбери ветку main и папку /(root), затем Save.
7. Подожди публикации — GitHub покажет адрес сайта в разделе Pages.

Перед публикацией проверь все сторонние ссылки и файлы. Сайт не хранит PKG-файлы: карточки ведут на внешние страницы загрузки.
